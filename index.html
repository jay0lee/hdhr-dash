Troubleshooting & Browser Permissions

1. Mixed Content (HTTPS $\to$ HTTP)

If hosted on GitHub Pages, Chrome blocks HTTP requests. Fix: Click the Tune/Sliders icon next to the URL $\to$ Site settings $\to$ set Insecure content to Allow.

2. Private Network Access (PNA)

If Chrome blocks public $\to$ private IP access, allow this origin via Terminal:

defaults write com.google.Chrome InsecurePrivateNetworkRequestsAllowedForUrls -array "https://<your-username>.github.io"
